# Thilanga Sumathipala — Official Profile Website

A modern and responsive redevelopment of the official **Thilanga Sumathipala** website, presenting his corporate leadership, political career, public relations activities, social initiatives, media, galleries, and contact information.

🌐 **Website Reference:** https://www.thilanga.lk/

---

## ✨ Features

- Responsive desktop, tablet, and mobile layouts
- Animated navigation and mobile menu
- Cinematic image and video hero sections
- Corporate, Political, and Public Relations pages
- Interactive image galleries and full-screen previews
- Scroll-triggered animations
- Responsive Google Maps integration
- Contact form with validation
- Per-page scroll position restoration
- Accessibility and reduced-motion support
